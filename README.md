# CodeAlpha_Sales-Prediction-using-Python

Welcome to my CodeAlpha Internship repository! This repository documents are for Task 4 of my internship journey, focusing on Sales Prediction using Python.

## Task Overview
Predict future sales based on advertising spend across TV, radio, and newspapers.
Clean and transform the dataset for analysis.
Develop a regression model to forecast sales.
Evaluate model performance using MSE and R-squared.
Generate actionable insights for marketing strategies.

## Knowledge Gained

This task helped me a lot by offering valuable insights.
Data Preparation: Skills in cleaning data and feature selection.
Regression Analysis: Understanding of linear regression and coefficient interpretation.
Model Evaluation: Experience with MSE and R-squared metrics.
Data Visualization: Proficiency in using Matplotlib and Seaborn for visual analysis.
Business Insights: Ability to derive actionable marketing strategies from data analysis.
